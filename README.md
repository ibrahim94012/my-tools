# My Tools — সেটআপ গাইড

## যা যা তৈরি করা হয়েছে
- `index.html` — পুরো ওয়েবসাইট (Google Sign-in → PIN সেট → ফিঙ্গারপ্রিন্ট → ড্যাশবোর্ড)
- `css/style.css` — লাইট, ব্লু থিম ডিজাইন
- `js/firebase-config.js` — আপনার Firebase config বসানোর জায়গা
- `js/app.js` — সম্পূর্ণ অ্যাপ লজিক
- `database.rules.json` — Realtime Database সিকিউরিটি রুলস

## ধাপ ১: Firebase প্রজেক্ট তৈরি করুন
1. https://console.firebase.google.com এ যান → **Add project**
2. প্রজেক্ট তৈরি হলে **Build → Authentication → Get started** এ যান
3. **Sign-in method** ট্যাব থেকে **Google** চালু (Enable) করুন

## ধাপ ২: Realtime Database চালু করুন
1. **Build → Realtime Database → Create Database**
2. যেকোনো লোকেশন বেছে টেস্ট মোডে শুরু করুন
3. **Rules** ট্যাবে গিয়ে এই প্রজেক্টের `database.rules.json` ফাইলের কন্টেন্ট পেস্ট করে **Publish** করুন
   (এতে প্রতিটি ইউজার শুধু নিজের ডেটা পড়তে/লিখতে পারবে)

## ধাপ ৩: Web App যোগ করুন ও Config কপি করুন
1. প্রজেক্ট Settings (⚙️) → **General** → **Your apps** → ওয়েব আইকনে (`</>`) ক্লিক করুন
2. একটি নাম দিয়ে অ্যাপ রেজিস্টার করুন
3. যে `firebaseConfig` অবজেক্ট দেখাবে, সেটি কপি করে `js/firebase-config.js` ফাইলে বসিয়ে দিন

## ধাপ ৪: Authorized domain যোগ করুন
- আপনি যেখানে সাইটটি হোস্ট করবেন (যেমন `yourdomain.com` বা Firebase Hosting এর ডোমেইন), সেটি
  **Authentication → Settings → Authorized domains** এ যোগ করুন — নাহলে Google Sign-in কাজ করবে না।

## ধাপ ৫: ফিঙ্গারপ্রিন্ট (WebAuthn) সম্পর্কে জরুরি তথ্য
- ফিঙ্গারপ্রিন্ট আনলক কাজ করতে সাইটটি অবশ্যই **HTTPS** এ চলতে হবে (লোকাল টেস্টের জন্য `localhost` এ চলবে)
- এটি ব্যবহারকারীর ডিভাইসের নিজস্ব বায়োমেট্রিক (আঙুলের ছাপ/ফেস আইডি) ব্যবহার করে — যেসব ডিভাইসে
  ফিঙ্গারপ্রিন্ট সেন্সর/সাপোর্ট নেই, সেখানে অ্যাপ স্বয়ংক্রিয়ভাবে এই ধাপ স্কিপ করে সরাসরি PIN ব্যবহার করবে
- এই ভার্সনে ফিঙ্গারপ্রিন্ট যাচাই ক্লায়েন্ট-সাইডে হয় (কোনো ব্যাকএন্ড সার্ভার ছাড়া) — এটি ডিভাইস আনলক
  সুবিধার জন্য যথেষ্ট, তবে ব্যাংকিং লেভেল সিকিউরিটির প্রয়োজন হলে ভবিষ্যতে একটি ব্যাকএন্ড দিয়ে
  WebAuthn assertion সার্ভার-সাইডে ভেরিফাই করানো ভালো

## কীভাবে চালাবেন
- `index.html` ফাইলটি যেকোনো স্ট্যাটিক হোস্টিং এ আপলোড করুন (Firebase Hosting / Netlify / Vercel ইত্যাদি)
- লোকাল টেস্টের জন্য: ফোল্ডারের ভেতর একটি লোকাল সার্ভার চালান, যেমন
  `npx serve .` অথবা VS Code এর Live Server extension — সরাসরি `file://` দিয়ে খুললে
  Google Sign-in ও ফিঙ্গারপ্রিন্ট কাজ নাও করতে পারে।

## Tools ফিচার কীভাবে কাজ করে
- ড্যাশবোর্ডের নিচে **+** বাটনে চাপ দিলে একটি ফর্ম খুলবে: নাম, বিবরণ, আইকন ও একটি `.html` ফাইল
- ফাইলটির সম্পূর্ণ কন্টেন্ট টেক্সট আকারে Realtime Database-এ (`users/{uid}/tools/{id}/html`) জমা হয়
- টুল কার্ডে ট্যাপ করলে সেই HTML একটি নিরাপদ `<iframe sandbox>` এ লোড হয়ে দেখা যায়
- **নোট:** Realtime Database প্রতিটি নোডে বড় সাইজের ডেটা রাখার জন্য উপযুক্ত নয় — তাই HTML ফাইলগুলো
  ছোট/মাঝারি সাইজের (কয়েকশ KB এর মধ্যে) রাখাই ভালো
